SmartCrawler provides an AI‑agent‑ready web data extraction engine. It offers structured, real‑time web data via a REST API and MCP protocol, supporting adaptive crawling, anti‑blocking resilience, and traceable snapshots. Designed for AI agents, it delivers clean, schema‑validated data for e‑commerce, competitor analysis, and market intelligence, with features like multi‑strategy engines, TLS fingerprinting, and scalable task queues.

**Areas:** AI Agents · API

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for SmartCrawler: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
